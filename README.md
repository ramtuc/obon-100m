# 会社まであと100m

お盆明けの月曜日。会社まで残り100mを歩く、短編の鬱・心理ホラーブラウザゲームです。

選択と行動によって、時刻、メンタル、出来事、そして主人公の結末が変化します。

## プレイ

**[ブラウザでゲームをプレイする](https://ramtuc.github.io/obon-100m/)**

スマートフォン・PCのブラウザに対応しています。BGMや効果音を聴く場合は、タイトル画面で音を有効にしてください。

## 遊び方

目的は、始業時刻とメンタルに気を配りながら、会社までの100mを進むことです。

- 「進む」で1mずつ会社へ近づきます
- 「立ち止まる」「引き返す」こともできます
- 行動や出来事によって時間が進み、9:00を過ぎると遅刻になります
- 選択によってメンタルが上下し、画面演出や結末が変化します
- イベントには取り返しのつかない選択肢が含まれることがあります
- 複数のエンディングと実績があります

ゲーム内のタイトル画面にある「遊び方」から、いつでも説明を確認できます。初回プレイ時にも説明が表示されます。

## 内容について

鬱、心理的圧迫、職場ストレス、事故、死を示唆する表現を含みます。苦手な方はプレイをお控えください。

## 音声

BGMとイベント効果音があります。右上の音声ボタンでオン・オフ、設定画面でBGM音量を調整できます。

ブラウザの自動再生制限により、最初のクリックまたはタップ後に音が始まる場合があります。

## 技術構成

HTML / CSS / JavaScriptのみで動作する静的サイトです。ビルド処理や外部ライブラリは必要ありません。

ローカルで確認する場合は、このリポジトリのルートでHTTPサーバーを起動してください。

```powershell
python -m http.server 8765
```

その後、`http://localhost:8765/` を開きます。
