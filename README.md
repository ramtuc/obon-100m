# 会社まであと100m

お盆明けの月曜日、会社まで残り100mを歩く短編ブラウザゲームです。

時間、メンタル、隠された従順度によって出来事と結末が変化します。鬱・心理ホラーおよび事故を示唆する表現を含みます。

## 遊び方

ブラウザで `index.html` を開くか、GitHub Pagesの公開URLへアクセスしてください。

- 進む
- 立ち止まる
- 引き返す
- イベントごとの選択肢を選ぶ

音声を有効にすると、BGMとイベント効果音が再生されます。

## 技術構成

HTML / CSS / JavaScriptのみで動作する静的サイトです。ビルド処理や外部依存はありません。
